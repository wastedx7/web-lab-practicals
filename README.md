# Web Lab Practicals

This repo contains the web technology practicals, experiments, and code for exam and viva preparation.

Each experiment lives in its own folder, like `exp-4`, `exp-6`, and so on. Open an experiment folder to find its source code and instructions.

## Running an experiment

Move into the experiment folder, install the dependencies, and start the project:

```bash
cd exp-4
npm install
npm run dev
```

Vite will show a local URL to open in your browser. The exact commands may vary slightly between experiments, so check the `instructions.md` file inside the folder if one is available.
