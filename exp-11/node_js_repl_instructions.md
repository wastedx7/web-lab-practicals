# Instructions: Running Arithmetic Operations in Node REPL

1. Open **Command Prompt** (Windows) or **Terminal** (macOS/Linux).

2. Verify Node.js is installed:
   ```bash
   node -v
   ```

3. Start the Node.js REPL environment:
   ```bash
   node
   ```

4. Execute the following arithmetic expressions one by one:
   ```javascript
   10 + 5
   20 - 8
   6 * 4
   20 / 5
   17 % 5
   2 ** 3
   ```

5. Observe the calculated output after pressing `Enter` for each line.

6. Exit the REPL session:
   ```javascript
   .exit
   ```
