# Instructions to Run and Test React Props and State

## 1. Navigate to the Project Directory

```bash
cd exp-5
```

## 2. Install Dependencies

```bash
npm install
```

## 3. Run the Application

```bash
npm run dev
```

## 4. Open in Browser

Open the URL displayed in the terminal, usually:

```text
http://localhost:5173/
```

## 5. Test the Application

1. Verify that the student name, course, and college are displayed correctly.
2. Verify that the counter initially displays `0`.
3. Click **Increase Count** and check that the count increments by 1.
4. Click **Decrease Count** and check that the count decrements by 1.
5. Verify that the displayed count updates immediately after each click.

## 6. Stop the Application

Press `Ctrl + C` in the terminal.
